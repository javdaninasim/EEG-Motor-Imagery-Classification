### 🧩 Project Components

#### 1. Data Loading & Trial Extraction
- Class: `EEGDataLoader`
- Notes:
  - Supports multiple .mat layouts (`cnt`, `s`, `X`) and marker formats (`mrk`, `pos` + `y`).
  - Sampling frequency: `fs = 100 Hz`
  - Trial length: `4.0 s` → samples_per_trial = 400
  - Produces X with shape `(n_trials, n_channels, samples_per_trial)` and binary labels `y` (0/1)
- Example prints from notebook:
  - "Shape EEG signal" (e.g. (190594, 59))
  - Final X shape in example: `(200, 59, 400)`
  - Balanced classes in example: 100 / 100

#### 2. Temporal Filtering
- Class: `TemporalFilter`
- Method: `bandpass_filter(data, lowcut=8, highcut=30, order=5)`
- Implementation: Butterworth band-pass (digital) and `scipy.signal.filtfilt` applied per trial & channel

#### 3. Feature Extraction — Common Spatial Patterns (CSP)
- Class: `CommonSpatialPatterns` (n_components = 6 in notebook)
- Steps:
  - Compute class covariance matrices (normalized by trace)
  - Combine covariances, perform eigen-decomposition, compute whitening
  - Transform and select spatial filters (top/bottom components)
  - Features: log-variance of CSP-projected signals
- Methods: `fit`, `transform`, `fit_transform`

#### 4. Classifiers
- Custom SVM with RBF kernel: `SVM_RBF`
  - Implemented with an SMO-like iterative optimizer over alphas
  - Kernel: RBF, gamma default handling (`'auto'` or numeric)
  - Methods: `fit`, `predict`, `decision_function`
- scikit-learn models used for comparison:
  - `SVC(kernel='rbf')`
  - `RandomForestClassifier`
  - `LinearDiscriminantAnalysis`
  - `MLPClassifier`

#### 5. Hyperparameter Tuning
- Function: `competition.tune_svm_hyperparameters` (uses `StratifiedKFold`)
- Grid used in the notebook:
  - C: [0.1, 1, 10, 100]
  - gamma: [0.01, 0.1, 1, 'scale']
- Example best CV in notebook: `C=0.1, gamma=scale` → CV Accuracy = 0.9000 (printed during tuning)

#### 6. Evaluation & Visualization
- Class: `ModelEvaluator`
  - Metrics: Accuracy, Precision, Recall, F1
  - Plots: confusion matrix, ROC curve (when scores available)
- Additional visualizations:
  - Sample EEG channels plot (`eeg_sample_channels.png`)
  - t-SNE before/after CSP (`tsne_comparison.png`)
  - Model evaluation plots for each model and final comparison plot

#### 7. Clustering (k-means)
- kmeans elbow + silhouette analysis to suggest cluster count
- Saves `kmeans_elbow_silhouette.png` when run

### 💡 Implementation Details (concise)

Temporal filtering:
- Butterworth band-pass (8–30 Hz) implemented per trial + channel using filtfilt.

CSP:
- Covariance per trial normalized by trace → average per class → combined covariance → whitening → eigen-decomposition → select top/bottom eigenvectors → project → log-variance features.

Custom SVM (RBF):
- RBF kernel matrix K(X,X) computed.
- Iterative alpha updates (SMO-like) with clipping between L/H, update bias b.
- After training: support vectors and corresponding alphas retained; predict via decision function.

Evaluation:
- Accuracy, precision, recall, F1 reported and confusion matrix / ROC plotted when scores available.

k-means:
- Elbow & silhouette used to estimate optimal k; saves plot `kmeans_elbow_silhouette.png`.
